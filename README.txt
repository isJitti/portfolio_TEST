วิธีเปิดเว็บไซต์
================
ดับเบิลคลิก index.html เพื่อเปิดเว็บได้ทันที
ไม่ต้องติดตั้งแพ็กเกจหรือเปิดเซิร์ฟเวอร์
หากย้ายหรือคัดลอกเว็บไซต์ ให้ยกโฟลเดอร์ Portfolio ทั้งโฟลเดอร์

โครงสร้างไฟล์
==============
index.html          หน้าเว็บหลัก ดับเบิลคลิกไฟล์นี้
README.txt          วิธีใช้งานและแผนผังโฟลเดอร์
assets/
  css/              ไฟล์ตกแต่งเว็บไซต์ styles.css และ projects.css
  js/               ไฟล์การทำงาน script.js
ผลงาน/
  AI/               รูปอบรม AI และ Prompt Engineering
  IoT/              รูปกิจกรรมและวงจร IoT
  Network/          รูปผลงาน Raspberry Pi และระบบเครือข่าย
  ฝึกงาน/           รูปกิจกรรมฝึกงาน รวมไฟล์ HEIC ต้นฉบับ
  เกียรติบัตร/       รูปเกียรติบัตรและภาพรับรางวัล
  มัธยมศึกษา/       ผลงาน ม.3
เอกสาร/
  การศึกษา/         ใบเกรดและหลักฐานการศึกษา
  มหาวิทยาลัย/      เอกสาร KU และ RMUTT
  ฝึกงาน/           เอกสารและหนังสือรับรองการฝึกงาน
  เกี่ยวกับเว็บไซต์/ แหล่งอ้างอิง GitHub และรายการย้ายไฟล์

การดูผลงาน
===========
เลือกประเภทผลงานด้วยตัวกรอง
กดรูปเพื่อดูภาพใหญ่ ใช้ปุ่มลูกศรซ้าย/ขวาเปลี่ยนภาพ และ Escape เพื่อปิด
หยุดหรือเปิดการเคลื่อนไหวได้ด้วยปุ่มด้านบน
ลิงก์ GitHub และเว็บสั่งอาหารต้องใช้อินเทอร์เน็ตเมื่อกดเปิด
ภาพ Smart POS เป็นภาพจำลองแนวคิดและข้อมูลตัวอย่าง ไม่ใช่ระบบขายจริง

หมายเหตุ
========
จัดย้ายไฟล์ต้นฉบับโดยคงชื่อไฟล์และเนื้อหาเดิม ไม่มีไฟล์ผลงานหรือเอกสารถูกลบ
ปรับเฉพาะพาธในหน้าเว็บและสคริปต์ตามตำแหน่งใหม่ โดยไม่เปลี่ยนดีไซน์
ไม่ควรเปลี่ยนชื่อหรือย้าย assets และผลงานโดยไม่แก้พาธในเว็บไซต์ด้วย
รายการย้ายไฟล์พร้อม SHA256 ก่อนย้ายอยู่ใน เอกสาร/เกี่ยวกับเว็บไซต์/รายการย้ายไฟล์.json
ค่า SHA256 ของ script.js ในรายการเป็นค่าก่อนปรับพาธ
ฟอนต์ใช้ฟอนต์ระบบ Apple บนอุปกรณ์ Apple และ Segoe UI / Tahoma บน Windows
เอกสารการศึกษาและหนังสือรับรองไม่ได้แนบแสดงในหน้าเว็บ
